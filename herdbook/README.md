# Herd Book

A cattle record book for the herd and for Dad's herd: cows by tag, breeding and due dates,
calvings, cattle bought and sold (with profit by group), expenses (grain, hay, miles to the
sale), treatments with meat-withdrawal dates and a medicine cabinet, Farmington Regional
Stockyards prices, and a calculator for selling beef direct (quarters, halves, wholes).

- Live at `/herdbook/` (and `herdbook.graceandgrithomeco.com` once that domain is added in Vercel).
- No server or account: records are saved in the browser on each device. Use **Settings & data**
  to export to Excel, download a backup, or save automatically to a folder (OneDrive) on a computer.
- Excel export/import uses SheetJS 0.18.5 from cdnjs.
